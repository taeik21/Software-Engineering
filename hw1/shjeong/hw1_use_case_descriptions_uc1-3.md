# Use case descriptions

# UC-1 회원가입

| Actor Action | System Response |
| --- | --- |
|  |   1. ID, 비밀번호, 이름, 전화번호, 이메일 입력 필드를 보여준다. |
| 2. ID, 비밀번호, 이름, 전화번호, 이메일을 입력하고 회원가입 버튼을 누른다. |  |
|  | 3. 회원가입이 완료되었다는 메세지를 출력한다. |

# UC-2 회원탈퇴

| Actor Action | System Response |
| --- | --- |
|  |   1. “정말 탈퇴하시겠습니까?” 라는 확인 메세지를 보여준다. |
| 2. 사용자가 회원탈퇴 버튼을 누른다. |  |
|  | 3. 회원탈퇴가 완료되었다는 메세지를 출력한다. |

# UC-3 로그인

| Actor Action | System Response |
| --- | --- |
|  |   1. ID와 비밀번호 입력 필드를 보여준다. |
| 2. ID와 비밀번호를 입력하고 로그인 버튼을 누른다. |  |
|  | 3. 로그인이 완료되었다는 메세지를 출력한다. |
