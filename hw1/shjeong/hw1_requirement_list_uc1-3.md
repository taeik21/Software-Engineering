# requirement list (uc1-3)

| No. | Requirement | Use case |
| --- | --- | --- |
| 1 | 시스템을 이용하려면 사용자는 회원 가입을 해야 한다. 회원의 필수 입력 정보는 ID, 비밀번호, 이름, 전화번호, 이메일 등이다. 관리자는 주어진 ID (admin)와 비밀번호 (admin)으로 로그인한다. | 회원 가입 |
| 2 | 회원은 언제든 탈퇴할 수 있으며, 탈퇴 시 모든 이용 권한과 데이터가 삭제된다. | 회원 탈퇴 |
| 3 | 관리자와 회원은 ID와 비밀번호로 로그인한다. | 로그인 |
